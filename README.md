# Doc-Helper 本地文档处理助手

> 面向不会用 Office / WPS 复杂操作的人。把"多表合并、批量替换、格式清洗"这类重复的文档工作，变成一个**点几下就能完成**的小工具。

本项目目前处于 **MVP 早期阶段（v0.1）**：核心架构已经跑通，已有 1 个可用的真实工具。适合小组内部试用、反馈需求，还**不适合**分发和对外发布。

---

## 它能做什么（目前）

在浏览器里操作，选一个工具 → 上传文件 → 点"开始运行" → 下载结果。全程在**本地**完成，文件不会上传到任何服务器。

| 现有工具 | 用途 | 输入 | 输出 |
|---------|------|------|------|
| **xlsx 多表合并** | 把多个 Excel 表格合并成一个工作簿，每个源文件占一个工作表 | 至少 2 个 `.xlsx` 文件 | 1 个合并后的 `.xlsx` |
| **xlsx 数据源清洗** | 清洗数据源：去前后空格、英文单词首字母大写、英文名只留一个空格、出生年份只留数字 | 1 个 `.xlsx` 文件 | 1 个清洗后的 `.xlsx` |

后续规划中还有：Excel 表格拆分、格式调整、Word 批量替换关键词、Word 多文档合并，以及一个"聊天生成新工具"的智能体（草稿确认制）。

## 怎么用

### 一、启动

需要电脑已装 **Node.js**（本项目用的是 Node 26）。打开终端（PowerShell），在项目根目录运行：

```powershell
node server/index.js
```

看到下面这行就说明启动成功：

```
Doc-Helper 已启动: http://localhost:3000
```

然后**用浏览器打开** `http://localhost:3000` 即可。

> 想换个端口：`$env:PORT=8080; node server/index.js`

### 二、用工具（示例：合并多个 Excel）

1. 进入主界面，看到"工具列表"，找到 **xlsx 多表合并**。
2. 点击它，进入调用页。
3. 把要合并的多个 `.xlsx` 文件**拖进虚线框**（或点击选择）。界面会提示至少需要 2 个，数量达到后"开始运行"按钮才会变亮。
4. 确认输出文件名（默认 `out.xlsx`），点**开始运行**。
5. 等待处理，完成后下方出现结果文件，点**下载**。

### 三、设置（可选）

右上角"设置"是给将来的智能体聊天功能配大模型用的。目前**还不需要**，也不影响现有工具使用。

## 项目结构（给非技术人员的地图）

```
Doc-Helper/
├── web/            # 网页界面：你在浏览器看到的一切
│   └── index.html  # 主界面
├── server/         # 本地后端：负责启动服务、调度工具、管理文件
├── tools/          # 工具库：每个工具 = 一个文件夹
│   └── xlsx-merge-sheets/   # "xlsx 多表合并"工具
├── vendor/officecli/  # 底层文档引擎（内置，处理文档的真正"工人"）
├── test/           # 自动化测试（保证工具不出错）
└── PRD.md          # 产品需求文档（推荐前端/产品同学看）
```

简单说：**你在 `web/` 点按钮 → `server/` 接到指令 → 调 `tools/` 里的工具 → 工具用 `vendor/officecli/` 真正干活**。
